# UI 间距优化需求理解图

**日期**: 2026-01-28

---

## 用户反馈的问题

**"目前侧边栏间距太大，左侧栏间距太小"**

这里：
- **侧边栏** = `#sidebar` （左侧窄栏，包含：技能管理、主题设置、模型设置）
- **左侧栏** = `#side-panel` （左侧面板，包含：工作空间选择器 + 对话列表）

---

## 当前布局问题

```
┌──────────────┬──────────────────────────────────┐
│              │                                  │
│  #sidebar    │        #side-panel             │
│  (侧边栏)    │        (左侧面板/左侧栏)         │
│              │                                  │
│ ┌────────┐   │  ┌────────────────────────────┐ │
│ │ ⚡ 技能 │   │  │ 📁 默认工作空间    ⚙️ ➕ │ │
│ │        │   │  ├────────────────────────────┤ │
│ │        │   │  │ 💬 新对话              ✕  │ │ ← 问题：太小
│ │        │   │  │                      2024  │ │   太挤！
│ │        │   │  │ 💬 旧对话1           ✕  │ │
│ │        │   │  │                      2024  │ │

    ↑ 太宽！
```

---

## 我的理解：需要调整两个地方

### 1. 缩小侧边栏 (#sidebar) 的间距

```
┌───────────────────┐
│ 📁 WORKSPACE    › │ ← padding: 12px 16px (太大)
│                   │
│ ⚡ 技能管理      › │ ← padding: 12px 16px (太大)
│                   │
│ 🌓 主题设置      › │ ← padding: 12px 16px (太大)
│                   │
│ 🤖 模型设置      › │ ← padding: 12px 16px (太大)
└───────────────────┘
     ↓ 太宽

┌─────────────────┐
│📁 WORKSPACE   › │ ← 改为 6px 10px (更紧凑)
│⚡ 技能管理     › │ ← 改为 6px 10px (更紧凑)
│🌓 主题设置     › │ ← 改为 6px 10px (更紧凑)
│🤖 模型设置     › │ ← 改为 6px 10px (更紧凑)
└─────────────────┘
    ↓ 刚好
```

### 2. 增大左侧面板 (#side-panel) 对话列表的间距

```
┌─────────────────────────────┐
│ 📁 默认工作空间      ⚙️ ➕  │

│ 💬 新对话              ✕  │
│                     2024   │ ← padding: 10px 12px (太小)
│                         │   margin-bottom: 2px (太挤)

│                     2024   │
│ 💬 旧对话2           ✕  │
│                     2024   │
└─────────────────────────────┘
        ↓ 太挤

┌─────────────────────────────┐
│ 📁 默认工作空间      ⚙️ ➕  │
├─────────────────────────────┤
│ 💬 新对话              ✕  │
│                     2024   │ ← padding: 16px 18px (宽松)
│                         │   margin-bottom: 6px (舒适)
│                         │
│ 💬 旧对话1           ✕  │
│                     2024   │
│                         │
```
