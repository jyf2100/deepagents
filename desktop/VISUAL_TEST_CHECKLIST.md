# 温暖自然 UI - 视觉测试清单

> **创建日期**: 2026-01-25
> **分支**: `feature/warm-natural-ui`
> **用途**: 验证温暖自然 UI 改造的视觉效果和交互体验

## 测试说明

1. 已切换到 `feature/warm-natural-ui` 分支
2. 已重新构建桌面应用（运行 `cd desktop && ./rebuild-electron.sh`）
3. 应用已启动并可正常使用

- [ ] **浅色主题**: 测试大地色系视觉效果
- [ ] **深色主题**: 测试温暖深棕色调视觉效果

## 1. 色彩系统测试

### 1.1 浅色主题（大地色系）

**预期效果**:
- 主背景色: `#F5F1E8` (浅米色)
- 文字颜色: `#4A4036` (深棕色)
- 强调色默认: `#D4A574` (浅金棕)

**验证点**:
- [ ] 背景呈现温暖的米色调，不是冷灰色
- [ ] 文字对比度足够，易于阅读
- [ ] 所有 UI 元素颜色协调统一
- [ ] 侧边栏、聊天面板、对话框背景一致

### 1.2 深色主题（温暖深棕）

**预期效果**:
- 主背景色: `#2D2620` (深咖啡色)
- 文字颜色: `#F5E6D3` (浅米白)
- 强调色默认: `#E8B87D` (浅金棕更亮)

**验证点**:
- [ ] 背景是深棕色调，不是纯黑
- [ ] 文字在深色背景上清晰可读
- [ ] 眼睛感觉舒适，不刺眼
- [ ] 与浅色主题形成温暖的对比

### 1.3 强调色系统

**6 种颜色**:
1. **Sand** (沙滩金) - `#D4A574` / `#E8B87D`
2. **Wood** (木棕) - `#BC8F5F` / `#DEB887`
3. **Rose** (玫瑰粉) - `#FF8FAB` / `#FFB5BA`
4. **Sunset** (日落红) - `#FF6B6B` / `#FF8FAB`
5. **Mint** (薄荷绿) - `#6BCF7F` / `#8FD99E`
6. **Sky** (天空蓝) - `#87CEEB` / `#A8D8EA`

**验证点**:
- [ ] 逐个切换强调色，观察实时变化
- [ ] 每种颜色在浅色/深色主题下都协调
- [ ] 颜色名称与实际视觉效果一致
- [ ] 默认选中 "Sand" (沙滩金)

## 2. 圆角和阴影测试

### 2.1 圆角系统

**预期值**:
- 小圆角: 8px (从 4px 增加到 8px)
- 中圆角: 12px (从 6px 增加到 12px)
- 大圆角: 16px (从 8px 增加到 16px)
- 超大圆角: 20px (从 10px 增加到 20px)
- 特大圆角: 24px (从 14px 增加到 24px)

**验证点**:
- [ ] 所有按钮使用更大的圆角，视觉更柔和
- [ ] 对话框圆角明显增大
- [ ] 输入框、卡片圆角统一协调
- [ ] 圆角大小感觉"温暖柔软"，不尖锐

### 2.2 阴影系统

**预期效果**:
- 阴影颜色: `rgba(139, 115, 85, alpha)` (暖棕色)
- 不再使用纯黑色阴影

**验证点**:
- [ ] 卡片、对话框的阴影呈现棕色调
- [ ] 阴影不会显得太重或太脏
- [ ] 悬停时阴影加深自然
- [ ] 整体视觉温暖，不冷硬

## 3. 视觉增强效果测试

### 3.1 按钮渐变效果

**预期效果**:
- 所有按钮有 135 度线性渐变
- 从强调色过渡到悬停色

**验证点**:
- [ ] 发送按钮有渐变效果
- [ ] 悬停时按钮上移 2px
- [ ] 点击时按钮轻微缩小 (scale 0.98)
- [ ] 对话框按钮保持纯色（不渐变）
- [ ] 过渡动画流畅 (0.3s)

### 3.2 输入框聚焦效果

**预期效果**:
- 聚焦时出现金色光晕
- 光晕颜色: `rgba(212, 165, 116, 0.15)`
- 输入框上移 1px

**验证点**:
- [ ] 点击输入框时看到温暖的金色光晕
- [ ] 光晕不是冷蓝色或纯黑色
- [ ] 输入框轻微上移
- [ ] 过渡自然流畅
- [ ] 失焦后效果消失

### 3.3 玻璃态效果

**预期效果**:
- 对话框、模态框有毛玻璃效果
- 背景模糊: `blur(20px)`
- 半透明背景

**验证点**:
- [ ] 主题对话框背景有模糊效果
- [ ] 能看到对话框背后的内容（模糊）
- [ ] 浅色模式是半透明白
- [ ] 深色模式是半透明棕
- [ ] 边缘有微妙的白色边框
- [ ] 效果现代、高级、不廉价

## 4. 动画系统测试

### 4.1 消息进入动画

**预期效果**:
- 消息从下方滑入
- 带弹性缩放效果 (scale 0.95 → 1.0)
- 持续时间 0.5s

**验证点**:
- [ ] 发送消息后看到消息从下往上滑入
- [ ] 有轻微的弹性/回弹效果
- [ ] 动画流畅不卡顿
- [ ] 多条消息连续进入时动画自然

### 4.2 思考指示器动画

**预期效果**:
- 三个圆点依次跳动
- 延迟: 0s, 0.2s, 0.4s
- 缩放 0.8 ↔ 1.2

**验证点**:
- [ ] AI 思考时显示三个圆点
- [ ] 圆点从左到右依次跳动
- [ ] 形成波浪效果
- [ ] 圆点颜色使用当前强调色
- [ ] 动画循环流畅

### 4.3 标签切换动画

**预期效果**:
- 标签悬停时上移 2px
- 激活标签缩放 1.05
- 面板内容淡入 (10px 下滑)

**验证点**:
- [ ] 鼠标悬停在标签上时标签上移
- [ ] 激活标签比其他标签大
- [ ] 切换标签时内容从下方淡入
- [ ] 所有过渡动画流畅

### 4.4 技能卡片悬停动画

**预期效果**:
- 悬停时上移 4px，缩放 1.02
- 阴影升级到 `--shadow-lg`

**验证点**:
- [ ] 鼠标悬停在技能卡片上时卡片抬起
- [ ] 卡片轻微放大
- [ ] 阴影加深营造悬浮感
- [ ] 点击时卡片轻微下沉
- [ ] 多个卡片悬停时独立动画

### 4.5 动画控制器

**预期效果**:
- 自动检测系统动画偏好
- `prefers-reduced-motion` 时禁用动画

**验证点**:
- [ ] 在系统设置中启用"减少动态效果"
- [ ] 重启应用，所有动画消失
- [ ] 关闭"减少动态效果"，动画恢复
- [ ] 控制台有相关日志输出
