## 快速开始

### 安装应用

1. 下载 `Cowork-0.0.1-arm64.dmg`（macOS ARM）或 `Cowork-0.0.1.dmg`（macOS Intel）
2. 打开 DMG 文件，将 `Cowork.app` 拖拽到 `应用程序` 文件夹
3. 从启动台或应用程序文件夹启动 Cowork

### 系统要求

- macOS 11.0 或更高版本
- 支持 Intel (x64) 和 Apple Silicon (arm64)

## 首次配置

### 欢迎向导

首次启动应用时，会显示配置向导。您需要至少配置一个 AI 服务提供商的 API Key。

#### 支持的服务商

| 服务商 | 支持的模型 | 说明 |
|--------|-----------|------|
| **OpenAI** | GPT-4、GPT-3.5 等 | 需要注册 [OpenAI API Key](https://platform.openai.com/api-keys) |
| **Anthropic** | Claude 系列 | 需要注册 [Anthropic API Key](https://console.anthropic.com/) |
| **Google** | Gemini 系列 | 需要注册 [Google API Key](https://ai.google.dev/) |

#### 配置步骤

1. 在配置对话框中选择对应的服务商
2. 填写 API Key
3. （可选）填写自定义 Base URL（适用于使用代理或第三方服务）
4. 点击"保存配置"

## 功能详解

### 1. 工作空间管理

#### 什么是工作空间？

工作空间是独立的文件隔离环境。每个工作空间有：
- 独立的文件存储目录
- 独立的对话历史
- 可配置的系统提示词

#### 创建工作空间

1. 点击顶部工作空间切换器
2. 选择"➕ 创建工作空间"
3. 填写：
   - **名称**：工作空间显示名称
   - **目录**：文件存储位置
   - **分类**：便于分组管理
   - **描述**：工作空间用途说明
4. 点击"创建"

#### 工作空间设置

点击工作空间名称右侧的 ⚙️ 按钮，可以：

- **编辑基本信息**：修改名称、分类、描述
- **配置系统提示词**：
  - 📋 **使用模板**：从预设模板中选择
    - 代码审查助手
    - 写作助手
    - 数据分析专家
    - 通用助手
    - 翻译助手
    - 学习辅导
  - 🤖 **AI 生成**：根据描述自动生成提示词
  - ✏️ **自定义**：完全自定义提示词内容
- **删除工作空间**：删除工作空间及其所有数据

#### 切换工作空间

点击顶部工作空间切换器，从下拉列表中选择其他工作空间。

### 2. 对话功能

#### 发送消息

1. 在底部输入框输入消息
2. 点击"发送"按钮或按 `Enter` 键
3. AI 将响应并显示在聊天区域

#### 消息类型

- **用户消息**：右侧显示，使用强调色背景
- **AI 消息**：左侧显示，使用次要背景色
- **操作日志**：显示 AI 执行的工具调用

#### 多轮对话

支持上下文多轮对话，AI 会记住之前的对话内容。

### 3. 技能系统

#### 什么是技能？

技能是预定义的工具集，可以扩展 AI 的能力。技能可以包含：
- 自定义工具函数
- 特定领域的提示词
- 专门的执行逻辑

#### 安装技能

**方式一：从本地目录导入**

1. 切换到"技能"标签页
2. 点击"➕ 上传技能"
3. 选择包含 `SKILL.md` 文件的目录
4. 点击"上传"

**方式二：从 GitHub 导入**

1. 切换到"技能"标签页
2. 点击"⬇️ GitHub 导入"
3. 输入 GitHub 仓库 URL（如：`https://github.com/user/repo`）
4. 点击"扫描并导入"
5. 勾选要导入的技能
6. 点击"导入"

#### 技能类型

- **👤 用户技能**：您自己创建的技能
- **📁 项目技能**：从项目目录自动加载的技能

#### 删除技能

1. 切换到"技能"标签页
2. 找到要删除的技能
3. 点击"🗑️"删除按钮

### 4. Human-in-the-Loop (HITL)

#### 什么是 HITL？

HITL（人机协作）让您在 AI 执行某些操作前进行审批，确保安全性。

#### 工具批准流程

当 AI 需要执行敏感操作时，会弹出工具批准对话框：

```
┌─────────────────────────────────────┐
│  工具执行确认                        │
├─────────────────────────────────────┤
│  Agent 即将执行以下操作：             │
│                                     │
│  工具：write_file                   │
│  参数：                             │
│    path: /path/to/file              │
│    content: ...                     │
│                                     │
│  [拒绝]  [批准]  [✓ 自动批准全部]    │
└─────────────────────────────────────┘
```

#### 批准选项

- **拒绝**：阻止此操作执行
- **批准**：允许此操作执行
- **自动批准全部**：后续所有工具自动批准，无需再次确认

### 5. 配置管理

#### 打开配置

点击侧边栏底部的 ⚙️ 设置按钮。

#### 配置项

**OpenAI 配置**
- **API Key**：OpenAI API 密钥
- **Model**：模型名称（如 `gpt-4o`、`gpt-4o-mini`）
- **Base URL**：API 端点（可选）

**Tavily 搜索**
- **API Key**：用于网络搜索功能（[获取密钥](https://tavily.com/)）

**代理设置**
- **HTTP Proxy**：HTTP 代理地址（如 `http://127.0.0.1:7890`）
- **HTTPS Proxy**：HTTPS 代理地址
- **No Proxy**：代理排除地址（如 `127.0.0.1,localhost`）

**SkillsLM 技能市场**
- **SkillsLM URL**：技能市场网页地址
  - 默认值：`https://skillslm.com`
  - 留空使用默认值
  - 可自定义部署的 SkillsLM 实例地址
  - 修改后立即生效，无需重启应用

### 6. 主题设置

#### 打开主题设置

点击顶部工作空间切换器右侧的 🌓 按钮。

#### 主题模式

- **☀️ 浅色**：使用浅色主题
- **🌙 深色**：使用深色主题
- **🔄 自动**：跟随系统设置自动切换

#### 强调色

可选择的强调色：

| 颜色 | 效果 |
|------|------|
| 🔵 蓝色 | 经典蓝色，默认选项 |
| 🟣 紫色 | 优雅紫色 |
| 🔴 粉色 | 活力粉红 |
| 🟠 橙色 | 温暖橙色 |
| 🟢 绿色 | 清新绿色 |
| 🔷 青色 | 现代青色 |

强调色会影响：
- 用户消息气泡
- 按钮悬停效果
- 链接和高亮元素
- 对话框提示元素

## 配置说明

### 配置文件位置

配置文件存储在 `~/.deepagents/.env`：

```bash
# OpenAI 配置
openai_api_key=sk-xxx
openai_model=gpt-4o
openai_base_url=https://api.openai.com/v1

# Anthropic 配置
anthropic_api_key=sk-ant-xxx
anthropic_model=claude-sonnet-4-5-20250929

# Google 配置
google_api_key=xxx
google_model=gemini-2-pro-preview

# Tavily 搜索
tavily_api_key=tvly-xxx

# 代理配置
http_proxy=http://127.0.0.1:7890
https_proxy=http://127.0.0.1:7890
no_proxy=127.0.0.1,localhost

# SkillsLM 技能市场
skillslm_url=https://skillslm.com

# 主题配置
theme=auto
accentColor=purple
```

### 配置热重载

修改 `.env` 文件后，无需重启应用，配置会自动重新加载。

## 常见问题

### Q1: 应用启动后显示"欢迎使用 Cowork"配置向导，但我已经有配置了？

A: 检查 `~/.deepagents/.env` 文件是否存在且包含有效的 API Key。如果配置文件不存在或为空，会显示首次启动向导。

### Q2: 为什么 AI 消息中出现了 `</strong>` 这样的 HTML 标签？

A: 这是一个已知的 markdown 渲染问题，在最新版本中已修复。请确保您使用的是最新版本的应用。

### Q3: 暗色主题下某些文字看不清楚？

A: 早期版本中存在硬编码颜色导致暗色主题显示问题。在最新版本中已全面修复，所有颜色都使用 CSS 变量，可正确响应主题切换。

### Q4: 工作空间的文件存储在哪里？

A: 每个工作空间在创建时指定存储目录。默认情况下，工作空间数据存储在您指定的工作空间根目录下。

### Q5: 如何备份我的对话历史？

A: 对话历史存储在应用内部，未来版本将支持导出功能。目前可以通过复制文本内容的方式手动备份。

### Q6: HITL 工具批准对话框可以关闭吗？

A: 可以。在工具批准对话框中点击"✓ 自动批准全部"，后续所有工具操作将自动批准，不再弹出确认对话框。重新启动应用后会恢复默认需要确认的状态。

### Q7: 技能文件应该包含什么？

A: 技能目录需要包含 `SKILL.md` 文件，描述技能的名称、描述和工具定义。示例：

```markdown
# 技能名称

## 描述
这个技能的功能说明

## 工具
- tool1: 第一个工具
- tool2: 第二个工具
```

### Q8: 代理配置不生效怎么办？

A: 检查以下几点：
1. 确认代理地址格式正确（如 `http://127.0.0.1:7890`）
2. 确认代理服务器正在运行
3. 如果某些地址不需要代理，添加到 `No Proxy` 字段

### Q9: 如何切换到其他 AI 模型？

A: 打开配置对话框，修改对应服务商的 Model 字段。例如：
- OpenAI: `gpt-4o`、`gpt-4o-mini`、`gpt-3.5-turbo`
- Anthropic: `claude-sonnet-4-5-20250929`、`claude-3-5-sonnet-20241022`
- Google: `gemini-2-pro-preview`、`gemini-1.5-pro`

### Q10: 应用支持 Windows 或 Linux 吗？

A: 当前版本仅支持 macOS。Windows 和 Linux 版本正在开发中。
